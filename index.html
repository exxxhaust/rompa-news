Project Rompa / Редактор

Карточки меню

Редактируйте заголовки, описания, изображения и ссылки для главного и ESC-меню. Данные публикуются в вашем репозитории GitHub.

Подключение к репозиторию

Сначала создайте публичный репозиторий и токен с доступом только к нему. Подробные шаги — в инструкции из архива.

Токен остаётся только в памяти этой вкладки и отправляется только в GitHub API. Не передавайте его другим людям.

Вводите токен только на странице, размещённой вами. Она должна использовать HTTPS. Все тексты, картинки и ссылки в публичном репозитории видны всем.

Содержимое карточек

Выберите меню и карточку. Ссылку откроет игрок после подтверждения.

Настройка карточки

После изменений нажмите «Опубликовать».

Только HTTPS. Оставьте пустым, если карточка не должна открываться.
PNG до 1 МБ, максимум 2048 × 2048 пикселей. Без картинки останется стандартный фон.

Предпросмотр
